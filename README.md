# linux dotfiles

Setup with fish and starship for prompt and terminal emulator as wezterm.

With rest of the setup with jj and git, with helix as editor and opencode for my ai cli tools.

## Install Additional .sh

```bash
# dependencies
pacman -S jujutsu opencode helix fish starship ripgrep fzf k9s git-delta wezterm
paru -S jjui-git ashell

# niri and stuff
pacman -S cachyos-niri cachyos-niri-settings ashell
```
